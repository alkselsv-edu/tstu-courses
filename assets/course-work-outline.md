# Примерное содержание курсовой работы

Для очной формы (React + API). В каждом разделе кратко опишите, что сделано в вашем проекте; без общих определений.

1. Введение
  - Цель и задачи
  - Краткое описание предметной области выбранной темы
2. Функциональные требования и технологии реализации
  - 2.1 Функциональные требования (список или таблица с привязкой к сущностям)
  - 2.2 Архитектурный стиль (клиент–сервер, REST; обоснование выбора подхода)
  - 2.3 Технологии реализации
    - 2.3.1 Технологии реализации серверной части
    - 2.3.2 Технологии реализации клиентской части (React, React Router, Redux Toolkit или Zustand, слой запросов к API)
  - 2.4 Дополнительные инструменты
3. Реализация серверной части
  - 3.1 Структура проекта
  - 3.2 Модели данных (сущности и связи; не менее трёх связанных сущностей)
  - 3.3 Программные интерфейсы
    - 3.3.1 Взаимодействие с БД
    - 3.3.2 Валидация данных
    - 3.3.3 Реализация бизнес-логики (в т.ч. поиск или фильтрация)
  - 3.4 Аутентификация и авторизация пользователей (JWT, проверка Bearer-токена, защита данных)
  - 3.5 Миграции базы данных
4. Реализация клиентской части
  - 4.1 Структура проекта
  - 4.2 Компоненты и маршруты (React Router; не менее трёх страниц)
  - 4.3 Интеграция с программными интерфейсами (RTK Query, TanStack Query или API-клиент; передача JWT)
  - 4.4 Работа с состоянием (Redux Toolkit или Zustand)
  - 4.5 Формы, валидация, индикатор загрузки и обработка ошибок API
5. Тестирование *(опционально, будет плюсом)*
  - 5.1 Функциональное тестирование
    - 5.1.1 Тестирование функциональности серверной части
    - 5.1.2 Тестирование компонентов клиентской части
  - 5.2 Пользовательское тестирование (сценарии из критериев приёмки)
6. Запуск и поддержка
  - 6.1 Настройка окружения для запуска (README, `.env.example`)
  - 6.2 Разворачивание приложения / *контейнеризация (опционально)*
  - 6.3 Документация для API / *OpenAPI, Swagger (опционально)*
7. Заключение
  - Результаты работы, соответствие поставленным задачам
  - Возможные направления развития
8. Список источников

Приложения *(по необходимости)*: скриншоты интерфейса, схема данных, примеры запросов к API.
